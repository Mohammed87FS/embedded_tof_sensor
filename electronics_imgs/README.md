# Photos

Parts of the ToF project, taken while building it.

- `vl53l3cx_tof_sensor_*`: Pololu VL53L3CX carrier #3416, the sensor
- `raspberry_pi5_*`, `raspberry_pi_27w_usbc_power_supply.jpg`, `raspberry_pi_micro_hdmi_cable.jpg`: Pi 5 in an aluminium case with two fans, 27 W USB-C supply, micro HDMI cable
- `breadboard_with_rpi_gpio_extension_board.jpg`, `gpio_ribbon_cable_*`, `40pin_*`, `idc_box_connector_male_2x10.jpg`: breadboard, GPIO extension board, ribbon cable and headers
- `10segment_led_bar_graph_display.jpg`, `buzzer_passive_*`: LED bar and buzzer for a proximity alarm. I built that and took it out again, the final version only shows the distance in the GUI.
- `jumper_wire_kit_*`: jumper wires and resistors
